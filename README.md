# Claude Code toolchain

## ✨ Marketplace

Plugins:

- **ARCHIVED** ~~[cc-caffeine](https://github.com/samber/cc-caffeine): Prevents your computer from sleeping while Claude Code works hard~~
- [cc-skills](https://github.com/samber/cc-skills): General purpose AI Agent Skills
- [cc-skills-golang](https://github.com/samber/cc-skills-golang): AI Agent Skills for production-ready Golang projects
- [dev-event-organizer-skills](https://github.com/samber/dev-event-organizer-skills): AI Agent Skills for technical event operations: conferences, meetups, hackathons, speakers, and sponsorships
- [developer-platform-skills](https://github.com/samber/developer-platform-skills): AI Agent Skills for platform and SDK developer experience: API design, integrations, marketplace strategy, and onboarding
- [developer-relations-skills](https://github.com/samber/developer-relations-skills): AI Agent Skills for developer relations: open source strategy, community programs, technical content, and developer GTM
- [godig](https://github.com/samber/godig): A MCP server for pkg.go.dev

## 🚀 How to use ?

```bash
/plugin marketplace add samber/cc

/plugin install cc-skills@samber
/plugin install cc-skills-golang@samber
/plugin install cc-caffeine@samber
/plugin install dev-event-organizer-skills@samber
/plugin install developer-platform-skills@samber
/plugin install developer-relations-skills@samber
/plugin install godig@samber
```
